## 3. Математические модели
 
Принятые обозначения: $\tau$ — номер шага, $u_\tau$ — входной сигнал, $y_\tau$ — выход объекта. Начальные условия во всех моделях нулевые.
 
### 3.1. Модель 1.9 (линейная)
 
Очередное значение выхода определяется тремя предыдущими значениями выхода и текущим входом:
 
$$
y_{\tau+1} = a_1 y_\tau + a_2 y_{\tau-1} + a_3 y_{\tau-2} + b_1 u_\tau,
\qquad y_0 = y_{-1} = y_{-2} = 0.
$$
 
Параметры: $a_1$, $a_2$, $a_3$, $b_1$.
 
### 3.2. Модель 2.1 (нелинейная)
 
Нелинейными здесь являются квадрат выхода на предыдущем шаге и синус предыдущего входа:
 
$$
y_{\tau+1} = a y_\tau - b y_{\tau-1}^{2} + c u_\tau + d \sin(u_{\tau-1}),
\qquad y_0 = y_{-1} = u_{-1} = 0.
$$
 
Параметры: $a$, $b$, $c$, $d$.
 
### 3.3. Модель 3.3 (дифференциальная)
 
Объект задаётся дифференциальным уравнением первого порядка
 
$$
\frac{dy}{dt} = -a y + b u,
$$
 
для численного решения которого применён явный метод Эйлера с шагом $\Delta t$:
 
$$
y_{\tau+1} = y_\tau + \Delta t\,(-a y_\tau + b u_\tau),
\qquad y_0 = 0.
$$
 
Параметры: $a$, $b$, $\Delta t > 0$. Схема устойчива при выполнении условия $|1 - a\Delta t| < 1$.
 
## 4. Входные воздействия
 
| Воздействие | Формула |
|---|---|
| Ступенчатое | $u_\tau = 1$ |
| Импульсное | $u_0 = 1$, $u_\tau = 0$ при $\tau > 0$ |
| Гармоническое | $u_\tau = \sin(\tau)$, аргумент в радианах |
 
В таблицах номер шага на единицу больше $\tau$, то есть первой строке соответствует $\tau = 0$.

## 6. Объектно-ориентированная архитектура
 
Базовый класс `Model` является абстрактным: в нём хранится имя модели и объявлен чисто виртуальный метод `calculateNextStep(uTau)`. Классы-наследники `Model1_9`, `Model2_1` и `Model3_3` содержат собственные коэффициенты и предыдущие значения сигналов, а метод расчёта реализуют в соответствии со своим уравнением. В функции `main` нужная модель создаётся через `std::unique_ptr<Model>`. Благодаря этому цикл моделирования не зависит от конкретной модели, а освобождение памяти происходит автоматически.
 
| Принцип | Как проявляется в программе |
|---|---|
| Абстракция | `Model` определяет единый интерфейс расчёта шага |
| Наследование | Три модели унаследованы от `Model` |
| Инкапсуляция | Коэффициенты и внутреннее состояние спрятаны в закрытых полях |
| Полиморфизм | `calculateNextStep` вызывается через указатель на `Model` |
 
Диаграмма классов (Mermaid):
 

## 7. Ввод, вывод и проверка данных
 
Программа запрашивает данные в таком порядке: количество шагов $n$, номер модели, коэффициенты выбранной модели, номер входного воздействия. При некорректном вводе выполнение прекращается с сообщением об ошибке. Допустимые значения:
 
| Поле | Допустимые значения |
|---|---|
| Количество шагов $n$ | целое число, большее нуля |
| Номер модели | 1, 2 или 3 |
| Коэффициенты | любые конечные числа |
| Шаг времени $\Delta t$ (модель 3.3) | число, большее нуля |
| Номер воздействия | 1, 2 или 3 |
 
Если значение выхода перестаёт быть конечным числом или его модуль становится чрезмерно большим (расчёт расходится), моделирование прерывается на соответствующем шаге с сообщением об ошибке. В результирующие данные попадают только корректно вычисленные шаги.
 
Результаты выводятся в консоль в виде таблицы со столбцами «Шаг», $u(\tau)$ и $y(\tau+1)$. Пример для модели 1.9, ступенчатого воздействия и $n = 5$:
 
```
Модель: Модель 1.9
 
       Шаг         u(tau)       y(tau+1)
----------------------------------------
         1         1.0000         1.0000
         2         1.0000         1.5000
         3         1.0000         1.9500
         4         1.0000         2.3750
         5         1.0000         2.7275
```
 
Эти же данные записываются в файл `result.csv` с полями `step`, `u_tau`, `y_next`, `model`, `signal`. При записи используется стандартная локаль, поэтому разделителем дробной части всегда является точка, и Python считывает файл без дополнительных преобразований.

## 9. Сборка и запуск
 
Для работы необходимы CMake, компилятор MSVC (Visual Studio Build Tools) и Python 3 с библиотекой Matplotlib; если Matplotlib не установлена, `build.bat` установит её автоматически.
 
Файл `build.bat` по очереди выполняет четыре этапа и выводит их ход в консоль:
 
1. `CONFIGURE PROJECT` — конфигурация проекта командой `cmake -S . -B build`;
2. `BUILD PROJECT` — сборка командой `cmake --build build --config Release`;
3. `RUN PROGRAM` — запуск `task_01.exe` и диалог с пользователем;
4. `VISUALISATION` — проверка наличия Matplotlib и запуск `visualise.py`.
Каждое из девяти сочетаний «модель — воздействие» запускается через `build.bat` отдельно: во всех запусках вводятся одинаковые $n = 20$ и коэффициенты из раздела 8, а различаются лишь номер модели и номер воздействия. После каждого запуска график и таблица сохраняются в папку `doc`.
 
## 10. Анализ результатов
 
- **Модель 1.9.** Под действием ступеньки выход монотонно возрастает и приближается к установившемуся значению $b_1/(1-a_1-a_2-a_3) = 5$; на 20-м шаге он составляет 4.7423. При импульсе выход затухает, так как все корни характеристического уравнения $z^3 - 0.5z^2 - 0.2z - 0.1 = 0$ по модулю меньше единицы (наибольший — около 0.865). При синусоидальном входе выход колеблется примерно в диапазоне от $-0.86$ до $1.33$.
- **Модель 2.1.** Квадрат выхода и слагаемое $\sin(u_{\tau-1})$ придают отклику нелинейный характер. Для ступеньки характерны затухающие колебания, после которых выход стабилизируется около 2.02; при импульсе отклик быстро спадает практически до нуля; при синусе размах выхода достигает примерно 1.7.
- **Модель 3.3.** При ступеньке выход экспоненциально стремится к $b/a = 1$ (на шаге $k$ он равен $1 - 0.8^k$), при импульсе убывает с множителем $1 - a\Delta t = 0.8$. На синусоидальный вход объект отвечает колебаниями с амплитудой около 0.2–0.3: он сглаживает входной сигнал, а максимумы выхода запаздывают относительно максимумов входа.
## 11. Проверка корректности
 
- **Ручной расчёт.** Первые шаги вычислены по формулам вручную и совпали с результатами программы:
  - модель 1.9, ступенька: $y_1 = 1$, $y_2 = 0.5 + 1 = 1.5$, $y_3 = 0.5 \cdot 1.5 + 0.2 \cdot 1 + 1 = 1.95$;
  - модель 2.1, ступенька: $y_1 = 1$, $y_2 = 0.5 + 1 + 0.5\sin(1) = 1.9207$;
  - модель 3.3, ступенька: $y_1 = 0.2$, $y_2 = 0.2 + 0.2\,(-0.2 + 1) = 0.36$.
- **Полный ручной расчёт для гармонического воздействия.** Для каждой из трёх моделей вручную посчитаны все 20 шагов; значения совпали с таблицами программы с точностью до четвёртого знака.
- **Независимая проверка.** Результаты всех девяти комбинаций сопоставлены с отдельной реализацией тех же формул на Python — расхождений не выявлено.
- **Некорректный ввод.** Проверены нечисловые значения, $n \le 0$, номера модели и воздействия вне допустимого диапазона, а также $\Delta t \le 0$: в каждом случае программа выдаёт сообщение об ошибке.
- **Расходимость.** Для модели 2.1 при $a = 2$, $b = 3$, $c = 4$, $d = 1$ и ступенчатом входе выход уже на 12-м шаге достигает порядка $10^{50}$, а на 18-м выходит за пределы `double`. Программа прерывает такой расчёт и сообщает об ошибке.
